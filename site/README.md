# Instant Heating and Air — Website

A fully-static marketing website for Instant Heating and Air, LLC (Phoenix, AZ — ROC #348556).

Built to rank. Every page has:

- Unique `<title>` (50–60 chars) and meta description (150–160 chars)
- Canonical URL, Open Graph, Twitter Card
- Geo meta tags (`geo.region`, `geo.placename`, `geo.position`, ICBM)
- JSON-LD schema: `HVACBusiness`, `WebSite`, `BreadcrumbList`, `Service`, `Place`, `FAQPage`, `BlogPosting` (where applicable)
- Semantic HTML with a single `<h1>` per page
- `sitemap.xml`, `robots.txt`, `site.webmanifest`
- Favicons and a 1200×630 OG image

---

## Deploy

This site is **100% static** — no build step at runtime, no server required. Drop the contents of `/site/` onto any static host:

### Option A: GitHub Pages (easiest)
1. Create a new repo (e.g. `instantheatingandair-com`).
2. Commit the entire contents of `/site/` to the `main` branch.
3. In repo Settings → Pages, select `main` as the source and `/ (root)` as the folder.
4. Point your domain's DNS at GitHub Pages (CNAME `instantheatingandair.com` → `<username>.github.io`).
5. Add a `CNAME` file to the repo root containing `instantheatingandair.com`.

### Option B: Netlify (recommended for custom domains)
1. Drag the `/site/` folder onto [netlify.com/drop](https://app.netlify.com/drop).
2. In the dashboard, add your custom domain and let Netlify issue the TLS certificate.

### Option C: Any shared host / S3 / Cloudflare Pages
Just upload `/site/` to the web root. No configuration needed beyond a `404.html` handler (provided).

## Regenerating the site

All pages are generated by `/build/build.py` from the data files in `/build/data/`. To change copy, edit the relevant data module and re-run:

```bash
python3 build/build.py
```

### What's where

| File | Purpose |
|---|---|
| `build/data/site.py` | NAP, brand, navigation, home FAQ, "why us" |
| `build/data/services.py` | All 10 service pages (title, meta, copy, FAQs, pricing) |
| `build/data/areas.py` | 10 service-area pages (local climate note, ZIPs, landmarks) |
| `build/data/reviews.py` | Seeded reviews — replace with real Google reviews post-launch |
| `build/data/posts.py` | 6 launch blog posts |
| `build/build.py` | The generator — renders every HTML page + sitemap |
